# Social Metadata & Asset Integration

**Date:** 2026-05-09  
**Status:** Approved

## Overview

Integrate the existing amber hexagon SVG assets into the site's favicon, generate a 1200×630 OG image card, and add a complete set of social metadata tags to `index.html`. Goal: solid, correct share card previews across LinkedIn, Twitter/X, Discord, Slack, iMessage, and Facebook.

## File Structure Changes

```
public/
  favicon.svg          ← content replaced with favicon-hexagon.svg (amber hexagon)
  og-image.png         ← generated by build script; committed as static brand collateral
scripts/
  gen-og.mjs           ← new: generates og-image.png via sharp
```

`src/assets/favicon-hexagon.svg` and `src/assets/logo-hexagon.svg` remain in place. The gen script reads hexagon geometry directly from `src/assets/logo-hexagon.svg`.

## OG Image Card (`og-image.png`)

- **Dimensions:** 1200×630px PNG
- **Background:** `#0a0a0f` (portfolio dark bg token)
- **Layout:** amber hexagon (~160px) on the left third; text block on the right two-thirds
- **Text block:** Name (`Randall LaPoint, Jr.`), title (`Interactive Learning Designer`), domain (`randalllapointjr.dev`)
- **Amber accent:** `#d4962a`
- **Font:** system sans-serif (no font file bundling required — geometry is simple enough)
- **Generation:** `scripts/gen-og.mjs` builds the card as an inline SVG string with hexagon geometry embedded, then rasterizes via `sharp`

## Build Integration

`package.json` changes:

```json
{
  "scripts": {
    "gen:og": "node scripts/gen-og.mjs",
    "build": "node scripts/gen-og.mjs && tsc -b && vite build"
  },
  "devDependencies": {
    "sharp": "^0.33.x"
  }
}
```

Vercel will run `pnpm run build` on each deploy, regenerating `og-image.png` automatically.

## Implementation Steps

1. Install `sharp` as a dev dependency
2. Replace `public/favicon.svg` content with `src/assets/favicon-hexagon.svg`
3. Write `scripts/gen-og.mjs`
4. Run `pnpm run gen:og` to produce `public/og-image.png`
5. Update `index.html` with full metadata block
6. Update `package.json` build script and add `gen:og` script
7. Commit everything (including `public/og-image.png`)
8. Verify with `pnpm run build && pnpm run preview`

## Out of Scope

- Dynamic per-page OG images (single-page app, one card is correct)
- Structured data / JSON-LD (can be added later)
- Twitter username `twitter:site` / `twitter:creator` tags (no Twitter handle specified)
