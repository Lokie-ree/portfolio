# Social Metadata & Asset Integration

**Date:** 2026-05-09  
**Status:** Approved

## Overview

Integrate the existing amber hexagon SVG assets into the site's favicon, generate a 1200×630 OG image card and a 180×180 Apple touch icon, and add a complete set of social metadata tags to `index.html`. Goal: solid, correct share card previews across LinkedIn, Twitter/X, Discord, Slack, iMessage, and Facebook.

## File Structure Changes

```
public/
  favicon.svg             ← content replaced with favicon-hexagon.svg (amber hexagon)
  og-image.png            ← 1200×630, generated by build script; committed to git
  apple-touch-icon.png    ← 180×180 square, generated by build script; committed to git
scripts/
  gen-og.mjs              ← generates both og-image.png and apple-touch-icon.png via sharp
  Inter-SemiBold.ttf      ← bundled font file for reliable text rendering on Vercel
```

`src/assets/favicon-hexagon.svg` and `src/assets/logo-hexagon.svg` remain in place. The gen script reads hexagon geometry directly from `src/assets/logo-hexagon.svg`.

Both generated PNGs are committed to git so `pnpm run preview` works without running `gen:og` separately. They are deterministic — re-running `gen:og` produces identical output unless branding changes.

**Font licensing:** Inter is released under the SIL Open Font License 1.1, which permits redistribution. Committing `Inter-SemiBold.ttf` to the repo is permitted.

## OG Image Card (`og-image.png`)

- **Dimensions:** 1200×630px PNG
- **Background:** `#0a0a0f` (portfolio dark bg token)
- **Layout:** amber hexagon on the left third, text block on the right two-thirds
- **Hexagon positioning:** `logo-hexagon.svg` has a 100×100 viewBox with hexagon centered at (50, 50). At `scale(2)` the geometry spans 200px and its center lands at (100, 100). `translate(140, 215)` shifts that center to **(240, 315)** — the vertical midpoint of the card. Transform used: `<g transform="translate(140,215) scale(2)">`
- **Text block:** left edge at x=460, vertically centered around y=315
  - Name: y=270, font-size=52px, fill `#f0ece4` (near-white)
  - Title: y=330, font-size=28px, fill `#a89e90` (muted)
  - Domain: y=410, font-size=22px, fill `#d4962a` (amber accent)
- **Font:** Inter SemiBold (weight 600), embedded as base64 in the SVG string for guaranteed identical rendering on any machine and on Vercel's Ubuntu build environment
- **SVG construction approach:**
  ```
  // 1. Load font
  const fontB64 = fs.readFileSync('scripts/Inter-SemiBold.ttf').toString('base64');

  // 2. Extract inner hexagon elements (strip <svg> wrapper, keep polygon/line/circle tags verbatim)
  const rawSvg = fs.readFileSync('src/assets/logo-hexagon.svg', 'utf8');
  const innerElements = rawSvg.replace(/<svg[^>]*>/, '').replace(/<\/svg>/, '').trim();

  // 3. Build card SVG
  const svg = `<svg xmlns="http://www.w3.org/2000/svg" width="1200" height="630">
    <style>
      @font-face {
        font-family: 'Inter';
        font-weight: 600;
        src: url('data:font/truetype;base64,${fontB64}');
      }
    </style>
    <rect width="1200" height="630" fill="#0a0a0f"/>
    <g transform="translate(140,215) scale(2)">${innerElements}</g>
    <text x="460" y="270" font-family="Inter" font-weight="600" font-size="52" fill="#f0ece4">Randall LaPoint, Jr.</text>
    <text x="460" y="330" font-family="Inter" font-weight="600" font-size="28" fill="#a89e90">Interactive Learning Designer</text>
    <text x="460" y="410" font-family="Inter" font-weight="600" font-size="22" fill="#d4962a">randalllapointjr.dev</text>
  </svg>`;

  // 4. Rasterize
  await sharp(Buffer.from(svg)).png().toFile('public/og-image.png');
  ```

**fill-opacity note:** `favicon-hexagon.svg` uses `fill-opacity="0.12"` and `logo-hexagon.svg` uses `fill-opacity="0.07"`. This is intentional — the favicon at 48px reads better with more fill presence; the larger logo benefits from a more transparent fill. Do not harmonize them.

## Apple Touch Icon (`apple-touch-icon.png`)

- **Dimensions:** 180×180px PNG
- **Background:** `#0a0a0f`
- **Layout:** hexagon centered; `logo-hexagon.svg` 100×100 viewBox → `scale(1.2)`, center at (50×1.2, 50×1.2) = (60, 60); `translate(30, 30)` puts center at **(90, 90)**. Transform: `<g transform="translate(30,30) scale(1.2)">`
- **Generation:** same script, separate call:
  ```
  const iconSvg = `<svg xmlns="http://www.w3.org/2000/svg" width="180" height="180">
    <rect width="180" height="180" fill="#0a0a0f"/>
    <g transform="translate(30,30) scale(1.2)">${innerElements}</g>
  </svg>`;
  await sharp(Buffer.from(iconSvg)).png().toFile('public/apple-touch-icon.png');
  ```

## Build Integration

`package.json` changes:

```json
{
  "scripts": {
    "gen:og": "node scripts/gen-og.mjs",
    "build": "node scripts/gen-og.mjs && tsc -b && vite build"
  },
  "devDependencies": {
    "sharp": "^0.33.0"
  }
}
```

**sharp on Vercel:** `sharp` uses platform-specific native binaries (`libvips`). After running `pnpm add -D sharp` on Windows, pnpm adds the Windows binary and records `@img/sharp-win32-x64` as an optional dependency in `pnpm-lock.yaml`. Vercel runs `pnpm install` before building, which adds the Linux/x64 binary (`@img/sharp-linux-x64`) for its Ubuntu environment alongside the Windows one. This coexistence is how pnpm handles platform-specific packages — no special configuration is required. **Critical:** commit the updated `pnpm-lock.yaml` after `pnpm add -D sharp` or Vercel will have an outdated lockfile and may fail.

## Font Sourcing

Download Inter SemiBold as a static TTF (not the variable font):

1. Go to `fonts.google.com/specimen/Inter`
2. Click **Download family**
3. Extract the zip → open `Inter/static/` folder
4. Find `Inter_18pt-SemiBold.ttf` (weight 600)
5. Rename to `Inter-SemiBold.ttf` and place at `scripts/Inter-SemiBold.ttf`

No subsetting required — the card uses only ASCII characters; the full TTF is ~300KB, acceptable for a dev dependency committed to git.

## Implementation Steps

1. Install `sharp`: `pnpm add -D sharp` — then verify `pnpm-lock.yaml` is updated and commit it
2. Download Inter SemiBold TTF (see Font Sourcing above) → `scripts/Inter-SemiBold.ttf`
3. Check `.gitignore` — ensure `public/og-image.png` and `public/apple-touch-icon.png` are **not** listed (they must be committed)
4. Replace `public/favicon.svg` content with the content of `src/assets/favicon-hexagon.svg`
5. Update `package.json`: add `gen:og` script and update `build` script
6. Write `scripts/gen-og.mjs` (see SVG construction approach above)
7. Run `node scripts/gen-og.mjs` to produce `public/og-image.png` and `public/apple-touch-icon.png`
8. Update `index.html` with full metadata block (keep existing `<meta name="description">`)
9. Commit everything: `public/favicon.svg`, `public/og-image.png`, `public/apple-touch-icon.png`, `scripts/gen-og.mjs`, `scripts/Inter-SemiBold.ttf`, `package.json`, `pnpm-lock.yaml`, `index.html`
10. Verify with `pnpm run build && pnpm run preview`; confirm favicon renders in browser tab
11. After domain transfer: validate with LinkedIn Post Inspector and Twitter Card Validator

## Cache Invalidation Note

LinkedIn and Facebook cache OG images aggressively (sometimes for weeks). If `og-image.png` ever changes after first deploy, use LinkedIn's Post Inspector (`linkedin.com/post-inspector`) and Facebook's Sharing Debugger (`developers.facebook.com/tools/debug`) to force a cache refresh manually.
